【被控端 · 2026-09-27 · 服务版】开机自启 + 崩溃自愈

════════════ 一、现在一共四层保险 ════════════

[1] 守护服务  RemoteControlService   ← 本次新增,已在运行
    账户 LocalSystem,启动类型=自动。开机就运行,不需要任何人登录。
    每 5 秒检查一次:被控端不在线就立刻把它拉起来。
    → 被任务管理器/杀软结束后,5 秒内自动恢复。这是计划任务做不到的。

[2] 计划任务  RemoteControlAgent    ← 登录时触发 + 最高权限
    主实例:带管理员权限,能操作任务管理器等提权窗口。

[3] 注册表 Run 键  HKCU\...\Run\RemoteControlAgent  ← 用户级兜底
    值里带 --backup 参数。

[4] 手动双击 RemoteControl.exe
    (已改成无需管理员,不再弹 UAC、不再"点不动")

四层共用一个端口 9999:谁先起来谁监听,后起来的发现端口被占就安静退出;
哪一个死了,剩下的会在 5 秒内补上。互不打架。

服务日志:本目录下的 service.log

════════════ 二、必读:两个限制 ════════════
(1) 关机的那个晚上 → 第二天开机后,【需要在这台电脑上登录一次 Windows】
    (锁屏状态也可以)。原因:用户态远控必须有桌面会话才能抓屏、发键鼠,
    没人登录时服务虽然活着,但没有会话可投递。
    想彻底免登录:在这台机运行 netplwiz,取消勾选
    "要使用本计算机,用户必须输入用户名和密码"。
(2) 千万不要移动或删除这个文件夹(RCSvc.exe 和 RemoteControl.exe
    必须一直在同一个目录里)。搬了位置就重新运行一次【安装守护服务.bat】。

════════════ 三、换一台电脑 / 重装 ════════════
1. 把整个文件夹拷过去
2. 右键【安装守护服务.bat】→ 以管理员身份运行
   一键完成:装服务 + 写 Run 键 + 立即启动 + 自检(会打印本机 IP 和 9999 端口状态)
3. 想卸载:运行【卸载守护服务.bat】

自检命令(管理员 CMD):
  sc query RemoteControlService        ← 应为 RUNNING
  sc qc    RemoteControlService        ← START_TYPE 应为 AUTO_START
  schtasks /Query /TN RemoteControlAgent /V /FO LIST | findstr /i "要运行"
  netstat -ano | findstr ":9999" | findstr LISTENING

════════════ 五、这次修掉的三个真 bug ════════════
[bug1] 自启任务永远指向旧 exe  ← 这就是你"换了新版重启后功能全没了"的真凶
  旧代码用 schtasks /Change /TN x /TR "路径" 刷新自启指向。
  实测这个命令在 Windows 上恒返回"错误: 拒绝访问"(/Change 不接受 /TR),
  路径一个字符都没改;但代码不看返回值,日志照样打印"已刷新"。
  → 你看到的是"成功",任务却一直拉起旧版本。
  已改为 schtasks /Create /F 重建,并检查返回值。

[bug2] 被控端 exe 被编译成"必须管理员运行"
  工程里写着 <UACExecutionLevel>RequireAdministrator</UACExecutionLevel>。
  后果:①双击弹 UAC,点了没反应就像"点不动";
        ②放进 Run 键的自启会被登录时静默跳过 → 第三层保险形同虚设。
  已改为 AsInvoker。计划任务那层用 RunLevel=Highest 强制提权,权限不丢。

[bug3] 只有一个自启入口,被拦掉就彻底掉线
  → 现在四层冗余,见上。

(本次未做的事:没有把被控端本体做成 LocalSystem 服务。
 原因:服务跑在会话 0(session 0),那里没有桌面、抓不到屏也发不了
 键鼠;主流程放进去会直接不可用。所以采用"服务只负责拉起,
 真正干活的被控端仍在用户会话里"的结构,和 AnyDesk 是同一个思路。)
