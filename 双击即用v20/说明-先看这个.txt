【RemoteControl 双端 · v20】2026-09-27

==================== 怎么用 ====================
不用脚本、不用 bat、不用右键"以管理员运行"。
1) 【被控端 Windows】RemoteControl.exe 拷到目标电脑 -> 双击 -> UAC 点【是】-> 完事。
   之后它自己常驻,并写进三层自启(服务 + 计划任务 + 注册表 Run)。
2) 【控制端】client.exe 双击 -> 输入被控端 IP -> 连接。
   首次双击会弹一次"开机自启已装好"的提示框,看到就说明成功了。
3) 【被控端 Android】RCAndroidAgent.apk 安装 ->
   - 打开 App,点【申请权限】(会申请 摄像头/存储;Android 11+ 会跳到"所有文件访问"设置页,手动打开)
   - 点【启动服务】-> 弹出屏幕录制授权 -> 允许
   - 点【无障碍设置】-> 找到 "RC Agent" -> 打开
   - 之后回到 App,状态栏应显示 IP;在控制端输入该 IP 即可连接。
   开机自启:App 已注册 BOOT_COMPLETED,重启后自动拉起(无需手动点)。

============== 本版改了什么(v20) ==============
【Android 被控端 - 补全三大功能】
 1) 文件管理(控制端的"文件"面板现在能用了):
    - 列目录 / 下载文件(断点续传)/ 上传文件 / 新建文件夹 / 删除 / 重命名
    - 默认根目录 = /storage/emulated/0 (即手机内部存储根)
    - Android 11+ 必须给"所有文件访问"权限,否则列出目录会报错,
      App 里点【申请权限】会直接跳到那个设置页。
 2) 摄像头:
    - 控制端发 CAMERA 命令即可开关手机摄像头,实时回传 JPEG 帧
    - 已支持分辨率/帧率/画质参数;自动选择最大可用分辨率
 3) 触摸/滑动流畅度:
    - 拖拽改用 GestureDescription.continueStroke 手势链(手指"跟手",不再一段段重放)
    - 20ms 节流,避免手势排队造成粘滞
    - 若手势链被系统打断,抬起时会用 swipe/tap 兜底,不会卡住
 4) 系统信息(SYSINFO):型号/系统版本/CPU/内存/存储/电量/分辨率/WiFi-IP 等
 5) 剪贴板同步 + 光标位置(控制端对应按钮)

【上一个坑(已修)】Android 端之前编译出来的 APK 里没有这些新类,
  原因是 dex 工具(d8 8.2.2)遇到"实现了泛型接口的类"会内部崩溃,
  导致打包失败后一直沿用旧 APK。现已绕开,并让构建脚本每次清空旧 class。

============== 排查 ==============
Android 端:打开 App 界面下方有实时日志。
  连不上 -> 确认手机和控制端在同一 WiFi;确认 App 状态显示 IP;确认屏幕授权还在。
  文件列表空/报错 -> 去设置给"所有文件访问"。
  摄像头无画面 -> 确认已给【摄像头】权限(App 内点申请权限),且没有别的 App 独占相机。
Windows 被控端:目录下有 agent.log;服务模式另有 service.log。

============== 注意 ==============
 - Android 端重启手机后需要【解锁一次】并保持屏幕亮过(系统要求首次媒体投影授权)。
 - Windows 被控端文件夹别改名/移动;真要搬,搬到新位置重新双击一次。
 - 彻底卸载(Windows):命令行执行 RemoteControl.exe --uninstall
 - 彻底卸载(Android):卸载 App 即可;若装过无障碍,系统会自动清理。
